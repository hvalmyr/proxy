К инструкции

Свой прокси с Hysteria 2 и sing-box

Прокси — это посредник между вашим устройством и сайтами. Hysteria 2 работает на арендованном компьютере, а sing-box — программа на вашем компьютере или телефоне, которая подключается к нему. Руководство подходит для Linux, macOS, Windows, Android, iOS и iPadOS.

Команды для

Уже есть файл настроек для телефона? Перейдите к подключению Android или iPhone и iPad. Если сервера ещё нет, начните с первого раздела.

Арендуйте сервер и подключитесь

VPS — небольшой компьютер в интернете, который вы арендуете у хостинга. Ubuntu — операционная система для этого компьютера. Когда сайт открывается через прокси, он видит адрес сервера.

Для примера возьмём hostvds.com. Подойдёт и любой другой хостинг, где можно арендовать сервер с Ubuntu, получить публичный IPv4 и открыть UDP 443.

В панели хостинга выберите Ubuntu 24.04 LTS и самый простой тариф с 1 ядром и 1 ГБ памяти. Перед оплатой напишите в поддержку: «Будет ли у моего сервера собственный публичный IPv4? Открыт ли входящий UDP на порту 443 или я могу открыть его сам? Сколько гигабайт в месяц включено?»

Публичный IPv4 — адрес, по которому сервер можно найти из интернета. UDP — способ передачи данных, а 443 — номер входа на сервере, которым пользуется Hysteria 2. Если хостер блокирует этот вход, выберите другой тариф или хостинг. Покупать имя сайта для этой инструкции не нужно.

У HostVDS на базовом тарифе HostVDS 1 скорость подключения сервера — до 50 Мбит/с. При создании сервера можно за доплату около 0,50 доллара в месяц выбрать опцию Unlimited Shared 100 Mbit/s. С ней нет лимита на объём переданных данных, а скорость подключения сервера — до 100 Мбит/с, вдвое выше базовой. Это предел подключения сервера. Фактическая скорость у вас может быть ниже.

Подготовьте ключ

SSH позволяет управлять арендованным сервером с вашего компьютера. На Mac откройте «Терминал» через Spotlight, на Linux найдите «Терминал» в меню, на Windows — PowerShell в меню «Пуск». Вставьте команду и нажмите Enter. Если в ответ появится номер версии, можно идти дальше.

ssh -V

На Debian и Ubuntu, если команды нет, установите клиент OpenSSH.

sudo apt update
sudo apt install openssh-client

На Windows, если команды нет, установите OpenSSH Client в PowerShell от имени администратора.

Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0

Ключ SSH — пара файлов для входа на сервер. Следующая команда создаёт такую пару в формате Ed25519. При запросе имени файла можно оставить стандартный путь, если он свободен. Если файл уже существует, используйте существующий ключ или выберите другое имя. Для нового ключа задайте парольную фразу.

ssh-keygen -t ed25519 -C "proxy-vps"

Выведите публичный ключ и скопируйте всю строку в панель управления VPS. Если имя файла отличается от стандартного, подставьте своё. Файл с .pub можно отдать хостингу. Файл без .pub — ваш личный ключ, храните его у себя.

Linux

cat ~/.ssh/id_ed25519.pub

macOS

pbcopy < ~/.ssh/id_ed25519.pub

Windows · PowerShell

Get-Content "$HOME\.ssh\id_ed25519.pub" | Set-Clipboard

Создайте VPS и подключитесь

В панели хостинга создайте сервер с Ubuntu 24.04 LTS и выберите добавленный публичный ключ. Узнайте IPv4 и имя пользователя в панели хостинга. Здесь SERVER_IP обозначает ваш адрес, а команды рассчитаны на вход под root — администратором сервера. Для образа с другим пользователем укажите его при входе и выполните sudo -i перед настройкой сервера.

ssh root@SERVER_IP

При первом входе SSH покажет отпечаток — короткий код, по которому можно узнать сервер. Откройте консоль сервера в панели хостинга и выполните команду ниже. Подтвердите вход, если коды совпадают.

ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub

Сервер Hysteria 2

Команды этого раздела выполняются на VPS в SSH-сессии с правами root.

Установите Hysteria 2

apt update
apt upgrade
apt install curl openssl nano ca-certificates ufw
curl -fsSL https://get.hy2.sh/ -o /tmp/hysteria-install.sh
less /tmp/hysteria-install.sh

После просмотра нажмите Q, запустите установщик и проверьте пользователя и группу службы.

HYSTERIA_USER=hysteria bash /tmp/hysteria-install.sh
hysteria version
systemctl show hysteria-server -p User -p Group
id hysteria

Создайте два пароля и сертификат

Две команды ниже создадут по одному паролю. Первый даёт устройству право подключиться. Второй нужен Salamander — функции, которая меняет вид данных при передаче. Сохраните их в менеджере паролей. Сертификат server.crt понадобится на каждом клиенте.

openssl rand -hex 32
openssl rand -hex 32
umask 077
openssl req -x509 -nodes -newkey ec \
  -pkeyopt ec_paramgen_curve:P-256 \
  -keyout /etc/hysteria/server.key \
  -out /etc/hysteria/server.crt \
  -days 365 \
  -subj "/CN=proxy.internal" \
  -addext "subjectAltName=DNS:proxy.internal"

TLS шифрует подключение и проверяет, что sing-box связался с вашим сервером. Для проверки нужен сертификат — файл server.crt. Если вы замените его на сервере, обновите профили на устройствах. proxy.internal — имя внутри сертификата. Регистрировать его как имя сайта не нужно.

Настройте службу

Выполните nano /etc/hysteria/config.yaml. Откроется nano — редактор текста в терминале. Вставьте настройки из блока ниже и подставьте свои пароли. В nano сохраните файл сочетанием Ctrl+O, затем нажмите Enter и Ctrl+X.

listen: :443

tls:
  cert: /etc/hysteria/server.crt
  key: /etc/hysteria/server.key

auth:
  type: password
  password: "AUTH_PASSWORD"

obfs:
  type: salamander
  salamander:
    password: "OBFS_PASSWORD"

Дайте службе доступ на чтение конфигурации и TLS-ключа. Команды рассчитаны на пользователя hysteria и его одноимённую группу. Если у службы задана другая группа, используйте её. server.crt можно читать без доступа к приватному ключу.

chown root:hysteria /etc/hysteria/config.yaml /etc/hysteria/server.key
chmod 640 /etc/hysteria/config.yaml /etc/hysteria/server.key
chown root:root /etc/hysteria/server.crt
chmod 644 /etc/hysteria/server.crt

Откройте порты и запустите сервер

UFW — программа, которая решает, какие подключения пускать на сервер. Добавьте правила в UFW и, если есть отдельный экран в панели хостинга, там тоже. Перед включением UFW убедитесь, что разрешили фактический порт SSH. Обычно для SSH нужен TCP 22 — соединение через вход под номером 22.

ufw allow 22/tcp
ufw allow 443/udp
ufw enable
ufw status
systemctl enable hysteria-server
systemctl restart hysteria-server
systemctl status hysteria-server --no-pager
ss -lunp 'sport = :443'

Строка active (running) означает, что программа запущена. Последняя команда должна показать, что она принимает подключения на порту 443. Проверьте вход SSH из второго терминала и затем завершите первую сессию командой exit.

Установите sing-box на своё устройство

Выберите свою систему вверху страницы и следуйте шагам ниже. Для этих настроек нужна версия sing-box 1.12 или новее.

Linux

Для Debian, Ubuntu, Fedora и Arch Linux можно скачать официальный установщик. Откройте скрипт через less, проверьте содержимое и нажмите Q перед запуском. Для других способов установки выберите свой дистрибутив в документации. Установка sing-box.

curl -fsSL https://sing-box.app/install.sh -o sing-box-install.sh
less sing-box-install.sh
sh sing-box-install.sh
sing-box version

macOS

Homebrew устанавливает программы через Терминал и умеет запускать sing-box в фоне. Если команда brew ещё не работает, сначала пройдите шаги на официальной странице Homebrew. Затем выполните две строки ниже.

brew install sing-box
sing-box version

Windows

Скачайте ZIP для Windows со страницы релизов. Для большинства ПК подойдёт windows-amd64, для Windows на ARM — windows-arm64. В Проводнике нажмите «Извлечь всё» и положите sing-box.exe непосредственно в «Загрузки».

Android

Установите официальное приложение sing-box for Android. Если у вас уже есть рабочий файл настроек для Android с расширением .json, перенесите его на телефон, например по USB, в папку «Загрузки». Это файл с паролями. Если он получен от другого человека, используйте только файл от того, кому доверяете.

Если файл уже есть, перейдите к импорту профиля. Если его нет, создайте ниже на компьютере отдельный профиль для Android и перенесите его на телефон.

iPhone и iPad

Установите sing-box MT из App Store. Если приложение недоступно, проверьте, доступно ли оно для региона вашей учётной записи Apple.

Если у вас уже есть готовый файл настроек для iPhone или iPad, сохраните его в приложении «Файлы» и перейдите к импорту профиля. Если файла пока нет, выберите «iPhone и iPad» вверху статьи и скачайте config.json через генератор ниже. Можно сделать это на телефоне или переслать файл с Mac на своё устройство через AirDrop. Это файл с паролями, поэтому передавайте его только на нужное устройство.

Получите сертификат для нового профиля

Сертификат позволяет приложению узнать именно ваш сервер. На компьютере откройте Терминал или PowerShell. В следующей команде замените SERVER_IP на адрес из панели хостинга. Если при настройке входили под другим именем, замените и root.

ssh root@SERVER_IP "cat /etc/hysteria/server.crt"

Скопируйте вывод от строки -----BEGIN CERTIFICATE----- до -----END CERTIFICATE----- включительно. Это публичная часть сертификата. Файл server.key содержит закрытый ключ и остаётся на сервере.

Сохраните файл настроек

Введите адрес из панели хостинга, два пароля, которые вы задали на сервере, и скопированный сертификат. Создайте результат отдельно для каждой системы, используя кнопки вверху. Профиль — это один набор настроек подключения. Для Android, iPhone и iPad генератор подставит параметры для выбранного устройства.

Всё, что вы вводите, обрабатывается в браузере. Сохранённый файл содержит пароли. Храните его у себя и передавайте на телефон как личный файл.

Дополнительные настройки подключения

С этой галочкой сайты в этих зонах по возможности открываются через вашего обычного провайдера. Снимите её, если хотите отправлять и их через сервер.

Начните с выключенной галочки. Если некоторые сайты через сервер долго висят на загрузке, включите её для проверки. Многие браузеры тогда попробуют загрузить сайт другим способом. Некоторые игры, звонки или приложения могут перестать работать. Если это случилось, снимите галочку и сохраните файл заново. Соединение sing-box с сервером продолжит работать тем же способом.

Запуск и проверка

Перед запуском отключите другой VPN. На телефоне или планшете sing-box использует системную функцию VPN, чтобы направлять интернет-подключения приложений через сервер. На компьютере выполните команды для своей системы один раз. Они включат sing-box сразу и настроят запуск после перезагрузки. Команды ниже предполагают, что скачанный файл называется config.json и находится в «Загрузках».

Linux · systemd

systemd — часть Linux, которая запускает программы в фоне. Команды рассчитаны на установку sing-box со службой systemd. Откройте Терминал. Выполняйте строки по очереди. Если проверка файла выдаст ошибку, исправьте её до запуска.

sudo install -d -m 755 /etc/sing-box
sudo install -m 600 "$HOME/Downloads/config.json" /etc/sing-box/config.json
sudo sing-box check -c /etc/sing-box/config.json
sudo systemctl enable --now sing-box
sudo systemctl restart sing-box
systemctl status sing-box --no-pager

Статус active (running) означает, что программа запущена. Если «Загрузки» называются иначе, переместите файл в Downloads или исправьте путь в команде.

macOS · фоновая служба Homebrew

Откройте Терминал. Команды используют Homebrew, установленный на предыдущем шаге. При запросе пароля Mac вводите его вслепую и нажмите Enter. Если проверка файла выдаст ошибку, сначала исправьте её.

BREW_DIR="$(brew --prefix)"
sudo install -d -m 755 "$BREW_DIR/etc/sing-box" "$BREW_DIR/var/lib/sing-box"
sudo install -m 600 "$HOME/Downloads/config.json" "$BREW_DIR/etc/sing-box/config.json"
sudo "$BREW_DIR/bin/sing-box" check -c "$BREW_DIR/etc/sing-box/config.json"
sudo "$BREW_DIR/bin/brew" services restart sing-box
sudo "$BREW_DIR/bin/brew" services info sing-box

Homebrew зарегистрирует системную службу macOS. Терминал после проверки можно закрыть.

Windows · Планировщик заданий

Нажмите «Пуск», найдите PowerShell и выберите «Запуск от имени администратора». Сначала скопируйте два файла из «Загрузок» в системную папку и проверьте настройки.

$dir = "$env:ProgramFiles\sing-box"
New-Item -ItemType Directory -Force $dir | Out-Null
icacls $dir /inheritance:r /grant:r '*S-1-5-18:(OI)(CI)F' '*S-1-5-32-544:(OI)(CI)F'
Copy-Item "$HOME\Downloads\sing-box.exe","$HOME\Downloads\config.json" -Destination $dir
& "$dir\sing-box.exe" check -c "$dir\config.json"

Если в последней команде нет ошибки, зарегистрируйте и запустите задание. Оно будет включать программу в фоне при запуске Windows, даже до входа в аккаунт.

$action = New-ScheduledTaskAction -Execute "$dir\sing-box.exe" -Argument 'run -c config.json' -WorkingDirectory $dir
$trigger = New-ScheduledTaskTrigger -AtStartup
$settings = New-ScheduledTaskSettingsSet -ExecutionTimeLimit ([TimeSpan]::Zero) -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -RestartCount 3 -RestartInterval (New-TimeSpan -Minutes 1)
Register-ScheduledTask -TaskName 'sing-box' -Action $action -Trigger $trigger -Settings $settings -User 'SYSTEM' -RunLevel Highest -Force
Start-ScheduledTask -TaskName 'sing-box'
Get-ScheduledTask -TaskName 'sing-box'

Состояние Running означает, что задание работает. Окно PowerShell можно закрыть.

Android · импорт профиля

  1. Откройте sing-box и перейдите в Profiles («Профили»). Нажмите + и выберите импорт из файла. Если версия приложения сначала предлагает тип профиля, выберите Local и укажите файл из «Загрузок».
  2. Назовите профиль, например «Мой прокси». На главном экране выберите его и нажмите кнопку запуска. В системном окне Android подтвердите запрос на VPN-подключение.
  3. Если хотите, чтобы Android сам поднимал подключение, найдите в системных настройках «VPN». Нажмите шестерёнку рядом с sing-box и включите «Постоянный VPN», если пункт доступен. Сначала проверьте обычное подключение и оставьте «Блокировать подключения без VPN» выключенным.

iPhone и iPad · импорт профиля

  1. Убедитесь, что config.json виден в приложении «Файлы». Скачанное через Safari обычно находится в папке «Загрузки».
  2. В sing-box откройте Profiles («Профили»), нажмите + и создайте профиль Local («Локальный»). В параметрах профиля выберите импорт из файла, укажите config.json и сохраните профиль. Назовите его, например, «Мой прокси».
  3. На главном экране sing-box выберите этот профиль и включите подключение. Когда iPhone или iPad попросит разрешить добавление настроек VPN, нажмите «Разрешить» и подтвердите действие кодом устройства, если система его запросит.
  4. После проверки можно включить Always On, если этот переключатель есть в приложении. Он нужен, чтобы sing-box автоматически восстанавливал подключение.

Проверьте, какой адрес видят сайты

Откройте Терминал или PowerShell и выполните команду. curl запрашивает страницу, а ifconfig.me в ответ показывает ваш адрес. В Windows, если curl не сработал, введите curl.exe ifconfig.me.

curl ifconfig.me

Выполните команду с выключенным и включённым sing-box. С включённым прокси должен появиться внешний адрес вашего сервера.

На телефоне или планшете откройте ifconfig.me в браузере. Посмотрите адрес с выключенным и включённым sing-box. С включённым прокси должен появиться внешний адрес сервера. Повторите через Wi‑Fi и, если на устройстве есть мобильный интернет, через мобильную сеть.

Диагностика и перенос VPS

Что делать, если не подключается
Тайм-аут или ошибка QUIC
Проверьте IPv4, состояние службы и правила для UDP 443 на сервере и у хостера. Сверьте пароль Salamander с конфигурацией клиента. Проверьте, проходит ли UDP из клиентской сети.
Ошибка авторизации
Сверьте auth.password на сервере с password в исходящем подключении клиента.
Ошибка x509
Так обозначается ошибка проверки сертификата. Проверьте срок действия сертификата, имя proxy.internal, время на обоих устройствах и наличие актуального файла server.crt рядом с JSON.
Ошибка TUN или пропал интернет
TUN — виртуальное сетевое подключение, через которое sing-box принимает трафик. Остановите клиент, проверьте права администратора и отключите второй VPN. В Windows параметр strict_route может влиять на работу приложений вроде VirtualBox. Подробности ограничений есть в документации. Параметры TUN.
Ошибка unknown field
Проверьте версию клиента и повторите sing-box check -c config.json в папке конфигурации.
systemctl status hysteria-server --no-pager
ss -lunp 'sport = :443'
journalctl -u hysteria-server -n 50 --no-pager

Как понять, где произошла ошибка

  1. Попробуйте открыть сайт с отключённым sing-box. Если сайт всё равно не открывается, сначала проверьте интернет. На телефоне переключитесь с Wi‑Fi на мобильную сеть.
  2. Если sing-box сразу выключается, откройте журнал. На Android журнал есть в приложении, на iPhone и iPad — в Settings → View Service Log, на Linux — по команде sudo journalctl -u sing-box -n 40 --no-pager. На macOS проверьте службу через sudo brew services info sing-box, на Windows посмотрите состояние и результат задания в Планировщике. Повторите команду check из инструкции установки.
  3. Если приложение показывает timeout, перепроверьте адрес в панели хостинга и запуск Hysteria командой ниже. Если всё работает только в одной сети, вероятно, другая сеть мешает этому типу подключения.
  4. Если в журнале x509, заново скопируйте публичный сертификат с сервера и пересоздайте профиль. Если приложение сообщает об ошибке JSON, скачайте новый файл через генератор и убедитесь, что его имя заканчивается на .json.
  5. Если на Android после остановки пропал интернет, проверьте системный пункт «Блокировать подключения без VPN» и отключите его для диагностики. Проверьте, что другой VPN выключен и у sing-box нет списка, который исключает нужное приложение.

Как временно отключить sing-box

В Терминале выполните sudo systemctl stop sing-box. Автозапуск останется включён. Чтобы вернуть прокси сразу, выполните sudo systemctl start sing-box.

Выполните sudo brew services stop sing-box. Это также выключит автозапуск. Чтобы снова включить и прокси, и автозапуск, выполните sudo brew services start sing-box.

В Планировщике заданий выберите задание sing-box и нажмите «Завершить». Чтобы запустить снова, нажмите «Выполнить». Если нужно отменить и запуск при включении ПК, нажмите «Отключить».

Выключите подключение на главном экране sing-box. Если оно включается снова, выключите Always On в приложении.

Нажмите кнопку остановки в sing-box. Если включали «Постоянный VPN», отключите его в системных настройках VPN.

Перенос VPS и дополнительные устройства

Перенос сервера

Сохраните зашифрованную копию /etc/hysteria/config.yaml, server.crt и server.key. На новом VPS установите Hysteria 2, восстановите файлы и права, откройте UDP 443 и запустите службу. Если сертификат остаётся действующим, а порт и пароли те же, на каждом клиенте достаточно заменить адрес в server. Проверьте новый сервер с одного клиента, прежде чем завершать работу старого.

Блок подключения для существующего конфига

При переносе VPS воспользуйтесь полным генератором выше. Этот блок пригодится, если вы уже редактируете настройки вручную: перенесите только изменившиеся поля в объект с тегом hy2. Оставьте proxy.internal, если перенесли сертификат из этой статьи. Другое имя должно совпадать с именем в сертификате. Сохраните проверку сертификата и используйте актуальный сертификат сервера.

Дополнительные устройства

Установите sing-box на каждом устройстве и выберите систему в генераторе и сохраните профиль для нового устройства. Все устройства расходуют один общий запас гигабайт по тарифу сервера.
