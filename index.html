К инструкции

Свой прокси с Hysteria 2 и sing-box

Один сервер Ubuntu и клиенты для Linux, macOS и Windows. Настроим подключение по UDP с проверкой TLS и раздельной маршрутизацией.

VPS и SSH

На компьютере sing-box принимает трафик через виртуальный интерфейс TUN. Подключения к локальным адресам идут напрямую. При включённом правиле для .ru, .su и .рф трафик к распознанным доменам этих зон тоже идёт напрямую. Остальной трафик направляется через VPS по Hysteria 2.

Для начала подойдёт VPS с Ubuntu 24.04 LTS, 1 vCPU и 1 ГиБ памяти, например у HostVDS. Уточните условия тарифа, наличие публичного IPv4, лимит трафика и возможность входящих подключений по UDP 443. Для этой схемы покупать домен необязательно.

Подготовьте ключ

Откройте терминал или PowerShell и проверьте наличие SSH.

ssh -V

На Debian и Ubuntu, если команды нет, установите клиент OpenSSH.

sudo apt update
sudo apt install openssh-client

На Windows, если команды нет, установите OpenSSH Client в PowerShell от имени администратора.

Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0

Если у вас ещё нет ключа Ed25519, создайте его. При запросе имени файла можно оставить стандартный путь, если он свободен. Если файл уже существует, используйте существующий ключ или выберите другое имя. Для нового ключа задайте парольную фразу.

ssh-keygen -t ed25519 -C "proxy-vps"

Выведите публичный ключ и скопируйте всю строку в панель управления VPS. Если имя файла отличается от стандартного, подставьте своё. Храните файл без .pub у себя на компьютере.

Linux

cat ~/.ssh/id_ed25519.pub

macOS

pbcopy < ~/.ssh/id_ed25519.pub

Windows · PowerShell

Get-Content "$HOME\.ssh\id_ed25519.pub" | Set-Clipboard

Создайте VPS и подключитесь

В панели хостинга создайте сервер с Ubuntu 24.04 LTS и выберите добавленный публичный ключ. Узнайте IPv4 и имя пользователя в панели хостинга. Здесь SERVER_IP обозначает ваш адрес, а команды рассчитаны на вход под root. Для образа с другим пользователем укажите его при входе и выполните sudo -i перед настройкой сервера.

ssh root@SERVER_IP

Перед подтверждением первого подключения сверьте отпечаток через консоль хостинга. Например, в консоли VPS можно вывести отпечаток ключа хоста Ed25519.

ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub

Сервер Hysteria 2

Команды этого раздела выполняются на VPS в SSH-сессии с правами root.

Установите Hysteria 2

apt update
apt upgrade
apt install curl openssl nano ca-certificates ufw
curl -fsSL https://get.hy2.sh/ -o /tmp/hysteria-install.sh
less /tmp/hysteria-install.sh

После просмотра нажмите Q, запустите установщик и проверьте пользователя и группу службы.

HYSTERIA_USER=hysteria bash /tmp/hysteria-install.sh
hysteria version
systemctl show hysteria-server -p User -p Group
id hysteria

Создайте два пароля и сертификат

Первая строка — пароль авторизации, вторая — пароль Salamander. Сохраните их в менеджере паролей. Сертификат server.crt понадобится на каждом клиенте.

openssl rand -hex 32
openssl rand -hex 32
umask 077
openssl req -x509 -nodes -newkey ec \
  -pkeyopt ec_paramgen_curve:P-256 \
  -keyout /etc/hysteria/server.key \
  -out /etc/hysteria/server.crt \
  -days 365 \
  -subj "/CN=proxy.internal" \
  -addext "subjectAltName=DNS:proxy.internal"

Создавайте сертификат на новом сервере. При замене сертификата на действующем VPS обновите server.crt на клиентах, иначе проверка TLS перестанет проходить. proxy.internal используется как имя в сертификате, поэтому создавать DNS-запись для него не требуется.

Настройте службу

Выполните nano /etc/hysteria/config.yaml, вставьте конфигурацию и замените значения паролей. В nano сохраните файл сочетанием Ctrl+O, затем нажмите Enter и Ctrl+X.

listen: :443

tls:
  cert: /etc/hysteria/server.crt
  key: /etc/hysteria/server.key

auth:
  type: password
  password: "AUTH_PASSWORD"

obfs:
  type: salamander
  salamander:
    password: "OBFS_PASSWORD"

Дайте службе доступ на чтение конфигурации и TLS-ключа. Команды рассчитаны на пользователя hysteria и его одноимённую группу. Если у службы задана другая группа, используйте её. server.crt можно читать без доступа к приватному ключу.

chown root:hysteria /etc/hysteria/config.yaml /etc/hysteria/server.key
chmod 640 /etc/hysteria/config.yaml /etc/hysteria/server.key
chown root:root /etc/hysteria/server.crt
chmod 644 /etc/hysteria/server.crt

Откройте порты и запустите сервер

Добавьте правила в UFW и, если есть отдельный экран в панели хостинга, там тоже. Перед включением UFW убедитесь, что разрешили фактический порт SSH. Здесь используется стандартный TCP 22.

ufw allow 22/tcp
ufw allow 443/udp
ufw enable
ufw status
systemctl enable hysteria-server
systemctl restart hysteria-server
systemctl status hysteria-server --no-pager
ss -lunp 'sport = :443'

Ожидаемый результат — active (running) и UDP-сокет на порту 443. Проверьте вход SSH из второго терминала и затем завершите первую сессию командой exit.

Клиент sing-box

Установите актуальную стабильную версию sing-box. Шаблон использует формат DNS, доступный с версии 1.12. Примеры ниже проверены командой sing-box check в версии 1.14.4.

Linux

Для Debian, Ubuntu, Fedora и Arch Linux можно скачать официальный установщик. Откройте скрипт через less, проверьте содержимое и нажмите Q перед запуском. Для других способов установки выберите свой дистрибутив в документации. Установка sing-box.

curl -fsSL https://sing-box.app/install.sh -o sing-box-install.sh
less sing-box-install.sh
sh sing-box-install.sh
sing-box version

macOS

Если установлен Homebrew, воспользуйтесь им. Архивы для Apple Silicon и Intel также есть на странице релизов. Релизы sing-box.

brew install sing-box
sing-box version

Windows · PowerShell

Установите через WinGet. Если он недоступен, скачайте архив Windows для своей архитектуры, распакуйте и поместите sing-box.exe рядом с будущим config.json. Для архива используйте .\sing-box.exe вместо sing-box во всех командах. Релизы sing-box.

winget install sing-box
sing-box version

Скачайте публичный сертификат

В локальном терминале подставьте адрес VPS. Если SSH настроен с отдельным ключом, добавьте -i ПУТЬ_К_КЛЮЧУ после scp. При входе под обычным пользователем подставьте его имя вместо root. Приватный server.key остаётся на VPS.

Linux и macOS

mkdir -p "$HOME/.config/sing-box"
cd "$HOME/.config/sing-box"
scp root@SERVER_IP:/etc/hysteria/server.crt ./server.crt

Windows · PowerShell

New-Item -ItemType Directory -Force "$HOME\sing-box" | Out-Null
Set-Location "$HOME\sing-box"
scp root@SERVER_IP:/etc/hysteria/server.crt ./server.crt

Конфигурация клиента

Сохраните результат как config.json в той же папке, что и server.crt. Одинаковый JSON подходит для трёх ОС: имя интерфейса TUN выбирается автоматически.

Поля можно оставить пустыми и заменить подстановки в сохранённом файле. Введённые значения обрабатываются только на этой странице.

Блокировка UDP может заставить браузер перейти с HTTP/3 на TCP. Он также может повлиять на другие приложения, использующие эти UDP-порты. Само подключение к Hysteria 2 использует UDP 443.

Открыть шаблон JSON

Замените 203.0.113.10, AUTH_PASSWORD и OBFS_PASSWORD. Адрес в примере зарезервирован для документации. Закрытые пароли хранятся в локальном JSON, ограничьте доступ к файлу своей учётной записью.

{
  "log": {
    "level": "info"
  },
  "dns": {
    "servers": [
      {
        "type": "local",
        "tag": "local"
      },
      {
        "type": "https",
        "tag": "remote",
        "server": "cloudflare-dns.com",
        "domain_resolver": "local",
        "detour": "hy2"
      },
      {
        "type": "fakeip",
        "tag": "fakeip",
        "inet4_range": "198.18.0.0/15",
        "inet6_range": "fc00::/18"
      }
    ],
    "rules": [
      {
        "domain_suffix": [
          ".ru",
          ".su",
          ".xn--p1ai"
        ],
        "action": "route",
        "server": "local"
      },
      {
        "query_type": [
          "A",
          "AAAA"
        ],
        "action": "route",
        "server": "fakeip"
      }
    ],
    "final": "remote",
    "reverse_mapping": true
  },
  "inbounds": [
    {
      "type": "tun",
      "tag": "tun-in",
      "address": [
        "172.19.0.1/30",
        "fdfe:dcba:9876::1/126"
      ],
      "auto_route": true,
      "strict_route": true
    }
  ],
  "outbounds": [
    {
      "type": "hysteria2",
      "tag": "hy2",
      "server": "203.0.113.10",
      "server_port": 443,
      "password": "AUTH_PASSWORD",
      "obfs": {
        "type": "salamander",
        "password": "OBFS_PASSWORD"
      },
      "tls": {
        "enabled": true,
        "server_name": "proxy.internal",
        "certificate_path": "server.crt"
      }
    },
    {
      "type": "direct",
      "tag": "direct"
    }
  ],
  "route": {
    "rules": [
      {
        "action": "sniff"
      },
      {
        "protocol": "dns",
        "action": "hijack-dns"
      },
      {
        "ip_is_private": true,
        "action": "route",
        "outbound": "direct"
      },
      {
        "domain_suffix": [
          ".ru",
          ".su",
          ".xn--p1ai"
        ],
        "action": "route",
        "outbound": "direct"
      }
    ],
    "auto_detect_interface": true,
    "default_domain_resolver": "local",
    "final": "hy2"
  }
}

В шаблоне sing-box использует локальный DNS для доменов прямого маршрута. Для остальных запросов A и AAAA он выдаёт временные адреса FakeIP и восстанавливает исходный домен при подключении. Другие DNS-запросы по умолчанию идут через прокси. Раздельная маршрутизация зависит от того, видит ли sing-box домен. Собственный DNS в приложении, кеш или обращение по IP могут повлиять на выбор маршрута.

Запуск и проверка

Остановите другой VPN, если он тоже управляет TUN. Перейдите в папку конфигурации перед запуском — от неё отсчитывается путь к server.crt. Для создания TUN нужны права администратора.

Linux и macOS

cd "$HOME/.config/sing-box"
chmod 600 config.json
sing-box check -c config.json
sudo "$(command -v sing-box)" run -c config.json

Windows · PowerShell от имени администратора

Set-Location "$HOME\sing-box"
sing-box check -c config.json
sing-box run -c config.json

Оставьте терминал открытым. Чтобы остановить прокси, нажмите Ctrl+C. При следующем запуске снова перейдите в папку и выполните команду run.

Сравните внешний IP до и после запуска на сайте вне доменов прямого маршрута. После запуска он должен совпадать с адресом выхода VPS. Отдельно откройте домен с суффиксом .ru и посмотрите в журнале клиента, выбрался ли исходящий маршрут direct. Проверить внешний IP.

Диагностика и перенос VPS

Тайм-аут или ошибка QUIC
Проверьте IPv4, состояние службы и правила для UDP 443 на сервере и у хостера. Сверьте пароль Salamander с конфигурацией клиента. Проверьте, проходит ли UDP из клиентской сети.
Ошибка авторизации
Сверьте auth.password на сервере с password в исходящем подключении клиента.
Ошибка x509
Проверьте срок действия сертификата, имя proxy.internal, время на обоих устройствах и наличие актуального файла server.crt рядом с JSON.
Ошибка TUN или пропал интернет
Остановите клиент, проверьте права администратора и отключите второй VPN. В Windows параметр strict_route может влиять на работу приложений вроде VirtualBox. Подробности ограничений есть в документации. Параметры TUN.
Ошибка unknown field
Проверьте версию клиента и повторите sing-box check -c config.json в папке конфигурации.
systemctl status hysteria-server --no-pager
ss -lunp 'sport = :443'
journalctl -u hysteria-server -n 50 --no-pager

Перенос сервера

Сохраните зашифрованную копию /etc/hysteria/config.yaml, server.crt и server.key. На новом VPS установите Hysteria 2, восстановите файлы и права, откройте UDP 443 и запустите службу. Если сертификат остаётся действующим, а порт и пароли те же, на каждом клиенте достаточно заменить адрес в server. Проверьте новый сервер с одного клиента, прежде чем завершать работу старого.

Блок подключения для существующего конфига

При переносе VPS замените объект с тегом hy2 в массиве outbounds. Оставьте proxy.internal, если перенесли сертификат из этой статьи. Другое имя должно совпадать с именем в сертификате. Держите актуальный server.crt рядом с конфигом.

Дополнительные устройства

Установите sing-box на каждом устройстве и перенесите config.json и публичный server.crt защищённым способом. Лимит трафика VPS общий для всех устройств.
